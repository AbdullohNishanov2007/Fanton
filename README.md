# Сайт ЧОП «Фантон» (React + Vite)

1. Установите Node.js 18+.
2. `npm install`
3. Положите картинки в папку `public/` (см. public/README.txt).
4. `npm run dev` — запуск для разработки.
5. `npm run build` — сборка в папку `dist/`, её содержимое загружают на хостинг.

Тексты, телефон и списки — в `src/data.js`. Стили — в `src/styles.css`.
